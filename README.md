# FreshScan – AI-Based Food Freshness Detection

FreshScan is an AI-powered food freshness detection system that uses deep learning and image classification to identify whether food items are fresh or spoiled from images.

## Features
- Detects food freshness from uploaded images.
- Uses a trained deep learning model for image classification.
- Displays prediction results to help users assess food freshness.
- Aims to promote food safety and reduce food waste.

## Technologies Used
- Python
- TensorFlow / Keras
- Machine Learning and Deep Learning
- Image Processing
- Flask or Streamlit (depending on the application interface)

## Project Files
- `app.py` – Application code
- `class_names.json` – Class labels used for predictions
- `food_freshness_model.keras` – Trained deep learning model
- `requirements.txt` – Python dependencies

## Objective
To develop a simple AI-based application that helps users assess food freshness using image classification.

## Future Enhancements
- Support for more food categories.
- Improved model accuracy with larger datasets.
- Mobile application integration.
- Real-time camera-based freshness classification.

**Note:** FreshScan provides an AI-based visual estimate and should not be treated as a guarantee that food is safe to eat.
